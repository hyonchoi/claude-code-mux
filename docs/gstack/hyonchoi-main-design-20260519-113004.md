## Open Questions

1. **Rollback toggle storage**: Should the rollback toggle live in TOML config (requires restart) or in-memory state (lost on restart)? TOML is durable but slow; in-memory is fast but ephemeral. **Default: TOML config** (durable, consistent with existing config model). Decision by: implementer at time of writing. If no decision by start of Layer 1, use TOML default.
2. **Health scoring window**: For deterministic fallback, how large is the "recent health" window? Last 10 requests? Last 60 seconds? Affects how quickly fallback adapts. **Default: last 10 requests** (simple, bounded memory, deterministic). Decision by: implementer. If no decision, use 10-request default.
3. **4xx deactivation codes**: Should all 4xx codes trigger temporary deactivation, or only 401/403/429? 400 and 404 may indicate a request-level problem, not a provider-level problem. **Default: 401/403/429 only** (provider auth/rate-limit signals). Decision by: implementer. If no decision, use 401/403/429 default.
