## Key Interactions to Verify
- Incoming request with valid Authorization preserves caller auth through primary upstream success.
- Retriable upstream failure transitions to allowed fallback candidate and returns success/terminal contract deterministically.
- Non-retriable auth/client upstream failure terminates without fallback.

## Edge Cases
- Missing/malformed Authorization header.
- Cross-provider fallback candidate rejection.
- Partial-write/streaming boundary where fallback must not continue after irreversible emission.
- Retry classification mismatch for provider-specific 4xx semantics.

## Critical Paths
- Auth immutability + same-provider fallback block path.
- Adapter-level retry classification correctness path.
- Terminal normalized error response path when fallback is exhausted or disallowed.
